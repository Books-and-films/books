# Прочитанные книги

Статический сайт со списком прочитанных книг. Работает на GitHub Pages, без сервера и сборки.

## Файлы

- `index.html` — сайт: вкладки «По работе» / «Художественное», поиск, фильтры, сортировка.
- `books.json` — все данные. Чтобы добавить или изменить книгу, правится только этот файл.

## Формат книги

```json
{
  "id": "the-goal",
  "shelf": "work",
  "title": "Цель",
  "title_original": "The Goal",
  "author": "Элияху Голдратт",
  "author_original": "Eliyahu Goldratt",
  "year": 1984,
  "pages": 400,
  "isbn": "9780884271956",
  "readings": [{ "year": 2011, "rating": 2 }, { "year": 2019 }],
  "scores": { "ease": 5, "interest": 5, "value": 5, "reread": 5 },
  "review": "Короткий отзыв"
}
```

- `shelf`: `work` (по работе) или `fiction` (художественное).
- `readings`: годы прочтения; `rating` (−2…+2) необязателен. На сайте показывается последняя поставленная оценка.
- `scores`: шкалы 1–5, где 5 всегда «хорошо»: `ease` — легко читается, `interest` — интересно, `value` — дала новое, `reread` — хочется перечитать. Любую можно пропустить.
- `author_original`: имя автора латиницей, для поиска по оригинальному названию.
- `isbn`: по нему строятся обложка (Open Library) и ссылки Open Library · WorldCat · Goodreads. Без ISBN ссылки ведут на поиск по названию и автору.

## Публикация

Репозиторий в организации Books-and-films → Settings → Pages → Source: Deploy from a branch → `main` / root.
